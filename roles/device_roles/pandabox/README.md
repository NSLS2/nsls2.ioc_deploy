# pandabox

Deploys an IOC for a PandABox position-compare/triggering device using the `pandablocks-ioc` Python package. The IOC is installed from PyPI as `pandablocks-ioc` (version `0.11.5`) into a Python 3.11 virtual environment.

## Example Configuration

Taken from [`examples/panda1/config.yml`](examples/panda1/config.yml):

```yaml
panda1:
  type: pandabox
  environment:
    PREFIX: "XF:31ID1-ES{PANDA:1}"
    PANDA_IP: "xf31id1-lab3-panda1.nsls2.bnl.local"
    ENGINEER: "Jakub Wlodek"
```

## Settings

| Setting | Required | Default | Description |
|---|---|---|---|
| `type` | Yes | - | Must be `pandabox`. |
| `environment.PREFIX` | Yes | - | IOC PV prefix, passed as the prefix argument to `pandablocks-ioc softioc`. |
| `environment.PANDA_IP` | Yes | - | IP address or hostname of the PandABox. |
| `environment.ENGINEER` | No | - | Name/contact info of the responsible engineer. Not in `schema.yml`; informational only and not used by the generated `st.cmd`. |

## Notes

- Installs the `python3.11` package via `dnf` on the target host.
- The `venv` directory in the IOC directory is deleted and recreated on every deployment, then the packages in `device_roles_pandabox_pip_dependencies` (default `pandablocks-ioc==0.11.5`) are installed with the venv's `pip`, and ownership is set to the softioc user/group.
- Does not use the standard EPICS `st.cmd`; a bash `st.cmd` is generated that exports the `EPICS_CA*`/`EPICS_PVA*` network variables from the host's `epics_interface` and runs `venv/bin/pandablocks-ioc softioc --screens-dir=<ioc dir>/bobfiles --clear-bobfiles <PANDA_IP> <PREFIX>`.
- Phoebus `.bob` screens are generated by the IOC into `<ioc dir>/bobfiles` (created at startup if missing).
